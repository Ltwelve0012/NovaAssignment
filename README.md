# Task Tracker

A sleek, modern, and persistent Task Tracker web application built with vanilla web technologies. Stay organized with a beautiful interface that works seamlessly across devices.

## ✨ Features

- **Quick Add**: Easily add tasks using the input field or by pressing Enter.
- **Task Management**: Toggle tasks as completed or pending with a single click.
- **Delete Tasks**: Remove individual tasks with the delete button.
- **Batch Actions**: Clear all completed tasks at once to keep your list focused.
- **Data Persistence**: Your tasks are saved locally in your browser using `localStorage`, so they persist even after a page refresh.
- **Live Counter**: Real-time tracking of pending tasks.
- **Premium Design**: Responsive layout with modern typography (Inter & Outfit) and dynamic blob background animations.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure.
- **CSS3**: Custom properties, Flexbox/Grid, and keyframe animations for a polished look.
- **JavaScript (ES6+)**: Functional logic for task management and state preservation.
- **Google Fonts**: [Inter](https://fonts.google.com/specimen/Inter) and [Outfit](https://fonts.google.com/specimen/Outfit) for modern typography.

- `index.html`: The main entry point and structure of the app.
